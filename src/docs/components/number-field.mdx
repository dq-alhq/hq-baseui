## Usage

```tsx showLineNumbers
import { NumberField } from "@/components/ui/number-field";
```

```tsx showLineNumbers
<NumberField>
  <NumberField.Label>Amount</NumberField.Label>
  <NumberField.Input />
</NumberField>
```

## Composition

Use the following composition to build an `NumberField`:

```text
NumberField
├── NumberField.Label
└── NumberField.Input
```

## Examples

### Controlled

Use `value` and `onValueChange` to control the number field state. The value is `null` when the field is empty.
