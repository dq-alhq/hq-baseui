## Usage

```tsx showLineNumbers
import { Popover } from "@/components/ui/popover"
```

```tsx showLineNumbers
<Popover>
  <Popover.Trigger render={<Button variant="outline" />}>
    Open Popover.
  </Popover.Trigger>
  <Popover.Content>
    <Popover.Header>
      <Popover.Title>Title</Popover.Title>
      <Popover.Description>Description text here.</Popover.Description>
    </Popover.Header>
  </Popover.Content>
</Popover>
```

## Composition

Use the following composition to build a `Popover`:

```text
Popover
├── Popover.Trigger
└── Popover.Content
    ├── Popover.Header
    |    ├── Popover.Title
    |    └── Popover.Description
    └── Popover.Footer
```
