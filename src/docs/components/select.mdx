## Usage

```tsx showLineNumbers
import { Select } from "@/components/ui/select";
```

```tsx showLineNumbers
const items = [
  { label: "Light", value: "light" },
  { label: "Dark", value: "dark" },
  { label: "System", value: "system" },
]

<Select items={items}>
  <Select.Trigger>
    <Select.Value placeholder="Theme" />
  </Select.Trigger>
  <Select.Content>
    <Select.Group>
      {items.map((item) => (
        <Select.Item key={item.value} value={item.value}>
          {item.label}
        </Select.Item>
      ))}
    </Select.Group>
  </Select.Content>
</Select>
```

## Composition

Use the following composition to build a `Select`:

```text
Select
├── Select.Trigger
│   └── Select.Value
└── Select.Content
    ├── Select.Group
    │   ├── Select.Label
    │   ├── Select.Item
    │   └── Select.Item
    ├── Select.Separator
    └── Select.Group
        ├── Select.Label
        ├── Select.Item
        └── Select.Item
```

## Examples

### Controlled

Use `defaultValue` for uncontrolled selects, or `value` and `onValueChange` to control the state.

<Demo component="select/select-controlled" />

### Align Item With Trigger

Use `alignItemWithTrigger` on `Select.Content` to control whether the selected item aligns with the trigger. When `true` (default), the popup positions so the selected item appears over the trigger. When `false`, the popup aligns to the trigger edge.

### Invalid

Add the `invalid` attribute to the `Field` component to show an error state.

```tsx showLineNumbers /data-invalid/ /aria-invalid/
<Field data-invalid>
  <Field.Label>Fruit</Field.Label>
  <Select.Trigger aria-invalid>
    <Select.Value />
  </Select.Trigger>
</Field>
```
