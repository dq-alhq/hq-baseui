## Composition

### Simple

Options placed directly under `NativeSelect` (no `NativeSelect.Group`).

```text
NativeSelect
├── NativeSelect.Item
├── NativeSelect.Item
├── NativeSelect.Item
└── NativeSelect.Item
```

### With groups

Use `NativeSelect.Group` to organize options into categories.

```text
NativeSelect
├── NativeSelect.Group
│   ├── NativeSelect.Item
│   └── NativeSelect.Item
└── NativeSelect.Group
    ├── NativeSelect.Item
    └── NativeSelect.Item
```

## Native Select vs Select

- Use `NativeSelect` for native browser behavior, better performance, or mobile-optimized dropdowns.
- Use `Select` for custom styling, animations, or complex interactions.

## API Reference

### NativeSelect

The main select component that wraps the native HTML select element.

```tsx
<NativeSelect>
  <NativeSelect.Item value="option1">Option 1</NativeSelect.Item>
  <NativeSelect.Item value="option2">Option 2</NativeSelect.Item>
</NativeSelect>
```

### NativeSelectOption

Represents an individual option within the select.

| Prop       | Type      | Default |
| ---------- | --------- | ------- |
| `value`    | `string`  |         |
| `disabled` | `boolean` | `false` |

### NativeSelect.Group

Groups related options together for better organization.

| Prop       | Type      | Default |
| ---------- | --------- | ------- |
| `label`    | `string`  |         |
| `disabled` | `boolean` | `false` |

```tsx
<NativeSelect.Group label="Fruits">
  <NativeSelect.Item value="apple">Apple</NativeSelect.Item>
  <NativeSelect.Item value="banana">Banana</NativeSelect.Item>
</NativeSelect.Group>
```
