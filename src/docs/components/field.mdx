## Usage

```tsx showLineNumbers
import { Field } from "@/components/ui/field"
```

```tsx showLineNumbers
<Field.Set>
  <Field.Legend description='This appears on invoices and emails.'>
    Profile
  </Field.Legend>
  <Field.Group>
    <Field>
      <Field.Label>Full name</Field.Label>
      <Input autoComplete="off" placeholder="Evil Rabbit" />
      <Field.Description>This appears on invoices and emails.</Field.Description>
    </Field>
    <Field invalid>
      <Field.Label>Username</Field.Label>
      <Input autoComplete="off" />
      <Field.Error>Choose another username.</Field.Error>
    </Field>
    <Field>
      <Switch />
      <Field.Label>Subscribe to the newsletter</Field.Label>
    </Field>
  </Field.Group>
</Field.Set>
```

## Composition

### Field

A single control with label, helper text, and validation.

```text
Field
├── Field.Label
├── Input / Textarea / Select
├── Field.Description
└── Field.Error
```

### FieldGroup

Related fields in one group. Use `Field.Separator` between sections when needed.

```text
Field.Group
├── Field
│   ├── Field.Label
│   ├── Input / Textarea / Switch / Select / Combobox
│   ├── Field.Description
│   └── Field.Error
├── Field
│   ├── Field.Label
│   ├── Input / Textarea / Switch / Select / Combobox
│   ├── Field.Description
│   └── Field.Error
├── Field.Separator
└── Field
    ├── Field.Label
    └── Input / Textarea / Switch / Select / Combobox
    ├── Field.Description
    └── Field.Error
```

### FieldSet

Semantic grouping with a legend and description, usually containing a `Field.Group`.

```text
Field.Set
├── Field.Legend
└── Field.Group
    ├── Field
    │   ├── Field.Label
    │   ├── Input / Textarea / Select / Combobox
    │   ├── Field.Description
    │   └── Field.Error
    └── Field
        ├── Field.Label
        ├── Field.Description
        └── Input / Textarea / Select / Combobox
```

## Anatomy

The `Field` family is designed for composing accessible forms. A typical field is structured as follows:

```tsx showLineNumbers
<Field>
  <Field.Label>Label</Field.Label>
  <Field.Description>Optional helper text.</Field.Description>
  {/* Input, Select, Switch, etc. */}
  <Field.Error>Validation message.</Field.Error>
</Field>
```

- `Field` is the core wrapper for a single field.

## Validation and Errors

- Add `invalid` to `Field` to switch the entire block into an error state.
- Render `Field.Error` immediately after the control to keep error messages aligned with the field.

```tsx showLineNumbers /data-invalid/ /aria-invalid/
<Field invalid>
  <Field.Label>Email</Field.Label>
  <Input type="email" />
  <Field.Error>Enter a valid email address.</Field.Error>
</Field>
```

## Accessibility

- `Field.Set` with `'description'` props keep related controls grouped for keyboard and assistive tech users.
- Apply `Field.Separator` sparingly to ensure screen readers encounter clear section boundaries.
