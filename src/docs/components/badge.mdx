## API Reference

### Badge

The `Badge` component displays a badge or a component that looks like a badge.

| Prop        | Type                                                                                                              | Default     |
| ----------- | ----------------------------------------------------------------------------------------------------------------- | ----------- |
| `variant`   | `"primary" \| "outline" \| "ghost" \| "destructive" \| "secondary" \| "warning" \| "success" \| "info" \| "link"` | `"primary"` |
| `className` | `string`                                                                                                          | -           |
