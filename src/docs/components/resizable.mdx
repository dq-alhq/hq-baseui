## About

The `Resizable` component is built on top of [react-resizable-panels](https://github.com/bvaughn/react-resizable-panels) by [bvaughn](https://github.com/bvaughn).

## Installation
<Install component='resizable' />

## Usage

```tsx showLineNumbers
import { Resizable } from "@/components/ui/resizable"
```

```tsx showLineNumbers
<Resizable orientation="horizontal">
  <Resizable.Content>One</Resizable.Content>
  <Resizable.Separator />
  <Resizable.Content>Two</Resizable.Content>
</Resizable>
```

## Composition

Use the following composition to build a `Resizable`:

```text
Resizable
├── Resizable.Content
├── Resizable.Separator
└── Resizable.Content
```
