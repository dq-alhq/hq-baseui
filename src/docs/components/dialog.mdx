## Usage

```tsx showLineNumbers
import { Dialog } from "@/components/ui/dialog"
```

```tsx showLineNumbers
<Dialog>
  <Dialog.Trigger>Open</Dialog.Trigger>
  <Dialog.Content>
    <Dialog.Header>
      <Dialog.Title>Are you absolutely sure?</Dialog.Title>
      <Dialog.Description>
        This action cannot be undone. This will permanently delete your account
        and remove your data from our servers.
      </Dialog.Description>
    </Dialog.Header>
    <Dialog.Body>
      Content goes here
    </Dialog.Body>
  </Dialog.Content>
</Dialog>
```

## Composition

Use the following composition to build a `Dialog`:

```text
Dialog
├── Dialog.Trigger
└── Dialog.Content
    ├── Dialog.Header
    │   ├── Dialog.Title
    │   ├── Dialog.Description
    |   └── Dialog.Body
    └── Dialog.Footer
```
