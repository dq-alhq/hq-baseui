## Installation
<Install component='textarea' />

## Usage

```tsx
import { Textarea } from "@/components/ui/textarea"
```

```tsx
<Textarea />
```

## Examples

### Field

Use `Field`, `Field.Label`, and `Field.Description` to create a textarea with a label and description.

<Demo component="textarea/textarea-field" />

### Disabled

Use the `disabled` prop to the `Field` component to disable the textarea. 

<Demo component="textarea/textarea-disabled" />

### Invalid

Use the `invalid` prop to the `Field` component to mark the textarea as invalid.

<Demo component="textarea/textarea-invalid" />

### Button

Pair with `Button` to create a textarea with a submit button.

<Demo component="textarea/textarea-button" />
