**HQ UI** is a modern React component library built on top of the [shadcn/ui](https://ui.shadcn.com) philosophy, powered by [Base UI](https://base-ui.com) and styled with [Tailwind CSS](https://tailwindcss.com).

It provides a collection of beautifully designed, accessible, and customizable UI components that help you build modern web applications faster — without sacrificing flexibility or control.

Rather than being a traditional component package that hides its implementation behind an abstraction, HQ UI gives you the freedom to own, customize, and adapt the components to fit your project's needs.

## What is HQ UI?

HQ UI brings together the best parts of modern frontend development:

- **shadcn/ui Philosophy** — Components are designed to be copied, customized, and owned by your project rather than locked behind a dependency.
- **Base UI** — Built on top of `@base-ui/react`, providing accessible, unstyled, and composable primitives.
- **Tailwind CSS** — Styled using utility-first CSS, making customization straightforward and consistent.
- **Modern Design** — Carefully crafted components with attention to detail, consistency, and user experience.
- **Developer Experience** — Designed with reusable patterns, predictable APIs, and a developer-friendly workflow.

## Why HQ UI?

Building a consistent user interface from scratch takes time. While existing component libraries provide convenient solutions, they can sometimes limit customization or introduce unnecessary abstractions.

HQ UI takes a different approach.

It combines the flexibility of the shadcn/ui ecosystem with the accessibility and composability of Base UI, while keeping styling entirely in your hands through Tailwind CSS.

The result is a component collection that gives you a solid starting point without taking away the freedom to make it your own.

## Built With

| Technology | Purpose |

| [Tailwind CSS](https://tailwindcss.com) | Styling and design system |
| [TypeScript](https://www.typescriptlang.org) | Type safety and developer experience |

## Design Philosophy

HQ UI follows a few principles:

- **Accessibility first** — Components build upon accessible primitives and interactions.
- **Composability** — Components should work together naturally and remain easy to extend.
- **Customizability** — You should be able to modify every aspect of the components.
- **Consistency** — A unified design language across components.
- **Simplicity** — Keep APIs intuitive and implementations maintainable.
